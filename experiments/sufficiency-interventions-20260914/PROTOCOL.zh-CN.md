# Sufficiency likelihood 与证据覆盖率：受控实验

本方案在新实验结果产生前冻结。只复用 gpu08 上 GPU 7、4 对应的两个 Qwen3.6-27B 服务，不训练、不新增模型服务、不重新检索。

正式服务器目录：`/data/zhaogangyi/picorer-eval/sufficiency-interventions-20260914-v2`。初始 pilot 保留在不带 v2 的目录，不纳入结果：其 JSON 写入器排序了工具 schema 字段，改变了原生 token 前缀。v2 保留完整 JSON 字段顺序，并在每次 original 重放推理前强制逐 token 核对历史前缀；不匹配直接失败。此修正不依据实验效果筛选结果。

## 测量与复现

- R：当前精确证据包包含的官方 MQuAKE 标准事实比例，不是证据条目数。
- Sufficiency likelihood：在原生 finish 前缀下 sufficient / insufficient 分支 token 的归一化概率。保存各副本原始 logprob 和 margin；分析先平均两个副本的 margin，再转换为 likelihood。不是主动选择 finish 的概率。
- 回答：原 MemoryArena 回答模板、系统提示、reasoning_effort=low、最大 16,384 输出 token；本次显式统一 temperature=0.7、top_p=0.8，每状态/条件 5 个独立 seed。与旧的单次最终答案不直接当作同一次采样比较。
- 调用原 benchmark 的 score_prediction，不另设 LLM judge。official substring exact match 为主，严格 exact match 为敏感性检查。空答案不是自动记错；保留原响应，沿用原 pipeline 的同证据 no-thinking fallback，仍失败则记录缺失。
- 不再运行 J。

## 实验一：证据组合

100 道题分别枚举全部 2^h 个标准事实子集，并使用事实位置的正序、逆序两个排列。使用原始带序号事实，不显示 gold、coverage、sufficient 等实验标签。每条未提供的事实以实际知识池中的无关事实替换；匹配近似词数，不声称 token 数严格相等。保留实际模型输入 token 数，报告长度差与长度调整敏感性分析。

模型上下文是根据原系统指令、问题和工具协议构造的干净实验输入，包含统一的 search/read 历史、当前 read observation 和固定预算。它不是未经修改的自然轨迹。所有条件源数固定，没有事实从工作笔记/旧 observation 泄漏。配对比较同题同顺序、仅一个事实槽不同的子集；比较标准事实相对无关事实的替换效应。

每条件两个服务各测一次 native likelihood，独立回答 5 次。先对题内同覆盖率的组合与顺序平均，再对题目平均，按 2/3/4 跳分别绘制。

## 实验二：搜索预览

对所有存在活动候选预览的真实状态构造 original、removed、irrelevant 条件。只修改 MEMORY 中缩进的预览正文；C handles、read receipts、预算、历史、工作笔记、证据包保持相同，执行逐字节差异审计。

若有未入包的标准事实，其完整陈述以及对应 hop answer 的字面文本均未出现在预览以外上下文和证据包中，则增设 relevant 条件，在预览中加入这些事实。不存在可用缺失事实的状态不硬造该条件。文本检查不等于证明不存在所有语义改写或模型参数知识；这是解释边界。

主要对比 relevant − irrelevant，辅助对比 removed − original、irrelevant − original。同状态同服务配对，再按题目平均。R 固定；预览不传给回答模型，不重复回答。记录所有条件缺失/排除及原因。

## 实验三：逐状态回答

全部 2,150 个状态，每个 5 次，共 10,750 次回答。按 action 发生前的状态恢复 ledger，严格使用当时的 UTF-16 原文坐标，合并重叠片段，验证原始与投影哈希。逐状态重新匹配 R；逐轨迹验证最终 ledger，并复现原最终回答 wrapper。

本次回答始终使用 exact package，禁用原 wrapper 可选的 full-parent expansion。因此新的答案测量针对当时 R 对应的证据，而非被扩展后的另一份证据。原始自然上下文的 S 继续使用既有测量；实验二 original 条件提供当前服务与旧测量的漂移检查。

## 统计与图表

100 个题目为独立抽样单位，三条轨迹、状态、证据组合、推理副本、答案采样均不作为额外独立题目。题目层面 95% bootstrap 区间，固定 seed 20260914。所有 100 题保留，64 道无已知标签冲突题为主分析，36 道已知冲突题以及全部 100 题为敏感性分析。

输出：证据覆盖率与 likelihood 的均值曲线、对应正确率曲线、预览配对效应、真实状态的正确率回归；相关系数和回归系数另存表格，不堆在图里。真实状态按题目等权；预测验证按题目分折，同题三个运行不跨训练/测试集。比较 R、likelihood/margin 及联合模型；只报告实际支持的数据范围。

## 运行门槛

先 smoke 检查，再前 10 题完整 pilot。只有所有输入审计通过、预期答案和 native 响应无缺失后，才进入全量。全量使用有上限的客户端线程，观察两个现有服务的等待请求和 KV cache；不改变设备归属。失败任务可按 ID 断点恢复，不覆盖完成响应。
