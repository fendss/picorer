# Picorer 充分性：十轮深度分析报告

## 先说结论

十轮分析共同指向一个比“R 和 S 有相关性”更具体的解释：

> **S 是一个稳定的模型内部信号，但它主要反映 agent 对当前可见上下文的作答准备度，不等于已经提交给答案阶段的标准证据完整度。R 决定证据是否真正可用于回答；当 R 完整以后，S 才表现出稳定的增量价值。**

这个区别来自 Picorer 的信息流。检索 agent 会看到搜索预览，但只有经过 `read` 的证据才进入正式 evidence handoff。搜索预览足以推动 S 转正、维持正值，甚至让 agent 结束检索，却不保证答案模型最终获得同样的信息。

因此，现有数据支持的是“R 作为证据门槛，S 作为门槛之后的准备度信号”，而不是“用 S 取代 R”。显式判断 J 则在尚未检索的负对照上就几乎全部回答“充分”，不能作为 S 的真值。

## 数据和分析原则

这里的“十轮”是对同一批完整数据进行十种相互衔接的深度分析，不是又运行了十遍模型。数据包括：

- 100 道多跳问题，每题独立运行 3 次；
- 300 条完整检索轨迹；
- 2,150 个冻结决策状态；
- 每个状态有两个独立服务副本，共 4,300 行测量；
- 每个状态副本对 J 采样 101 次，共 434,300 次；
- 全部 2,150 个原始 context 都完成了搜索预览中的标准证据匹配；
- 最终答对 133 / 300，正确率为 44.3%。

全文使用三个量：

- **R：** 经过 `read`、可以进入答案阶段的标准证据覆盖率；R 完整表示整条标准证据链均已提交。
- **S：** 原生 `finish` 协议中，“sufficient”相对“insufficient”的 logit margin；S 为正表示模型更偏向充分。
- **J：** 对同一状态显式询问“证据是否充分”后，重复采样得到的充分回答比例。

所有不确定性范围都以 benchmark question 为重采样单位，保留同一道题的三轮轨迹和全部状态结构。默认进行 5,000 次重采样。这样不会把同一题中的多个状态错误地当成独立样本。

## 第一轮：先确认 S 不是测量噪声

两个模型服务运行相同权重，但独立返回测量结果。2,150 个状态上的两份 S 几乎完全一致：相关系数为 0.9995，组内相关系数为 0.9995，平均绝对差为 0.083，正负符号只在 1.0% 的状态上不同。

![两个副本的 S 一致性](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/01-native-replica-agreement.png>)

**图 1｜两个副本的 S 测量。** 红线表示完全相等，六边形颜色表示状态密度。绝大多数状态紧贴等值线。

J 在两个副本之间也高度可复现，相关系数为 0.980。这里必须区分“可复现”和“有效”：一个受到 prompt 系统性诱导的测量仍然可以高度可复现。第一轮只说明后续观察到的 S 变化不是服务随机噪声造成的。

## 第二轮：用尚未检索的状态检验 J

每条轨迹的第一个状态还没有执行任何检索，是最自然的负对照。在这 300 个状态中，原生 S 没有一次为正；显式 J 却在 297 个状态上以多数票判断“证据充分”。J 的中位充分回答比例达到 0.842，5% 到 95% 分位范围仍高达 0.614 到 0.950。

![尚未检索时 J 的分布](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/02-explicit-j-negative-control.png>)

**图 2｜J 的负对照失败。** 虚线是 0.5 多数票阈值，深色实线是中位数。几乎整个分布都位于“充分”一侧。

这不是 S 与 J 孰真孰假的比较，而是说明 J 缺少最基本的区分能力。当前 prompt 产生了强烈的“sufficient”回答先验，因此不能用 J 验证 S，也不能把 101 次采样带来的低方差误认为高效度。

## 第三轮：还原证据获取事件的先后次序

把每条轨迹的关键事件放到归一化检索时间上，可以看到稳定的顺序：先在搜索预览中看见证据，随后 S 转正，再把证据正式提交。

各事件在“最终发生过该事件的轨迹”中的中位时间分别是：

- 看见首条标准证据：0.375；
- S 首次转正：0.400；
- 提交首条标准证据：0.600；
- 看见完整标准证据链：0.750；
- 提交完整标准证据链：1.000。

![关键事件的累计发生顺序](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/03-event-ordering.png>)

**图 3｜证据可见、S 转正与证据提交的时序。** 曲线越靠左，事件越早发生；终点低于 100% 表示部分轨迹始终没有发生该事件。

在同时看见过标准证据且 S 转正的 289 条轨迹中，214 条在标准证据第一次出现在 context 的同一个状态转正，66 条随后转正，只有 9 条更早转正。另一方面，在同时 S 转正并提交过证据的 283 条轨迹中，231 条是 S 先转正、之后才提交首条证据；两者的中位间隔为 1 步。

差距在完整证据链上更大：173 条最终提交完整证据链的轨迹中，172 条在 R 完整以前就已经出现正 S；S 到完整提交的中位距离为 3 步。S 的时序因此更贴近“证据进入视野”，而不是“证据完成 handoff”。

## 第四轮：S 首次转正时，模型到底看到了什么

如果只统计已经 `read` 的证据，241 / 300 条轨迹在 R 仍为 0 时就第一次出现正 S。但重新检查模型实际可见的搜索预览后：

- 293 条出现过正 S 的轨迹中，274 条在首次转正状态的当前预览里就含有至少一条可精确匹配的标准证据，占 93.5%；
- 按“此前预览中见过的证据 + 已提交证据”统计，253 条是在只见到部分证据链时转正；
- 27 条是在已经见到完整证据链时转正；
- 只有 13 条在完全没有匹配标准证据时转正；
- 7 条始终没有转正。

![首次正 S 时的证据状态](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/04-first-positive-evidence.png>)

**图 4｜首次正 S 的两种证据口径。** 上条只统计正式提交的证据；下条加入搜索预览。原本看起来大面积“无证据转正”的状态，绝大多数实际已经看见部分证据。

所以，“S 大量在没有任何证据时盲目自信”不是最符合数据的解释。更准确的结论是：**S 通常由部分、暂时可见、尚未提交的证据触发。**

## 第五轮：搜索预览和正式提交分别让 S 改变多少

为了区分时间自然推进与证据事件本身，我们分析相邻状态的 S 变化，并同时控制前一状态的 S、前一状态的 R、归一化时间及其平方项、标准证据跳数和实验轮次。

905 个没有新标准证据进入视野或提交的转移中，S 平均只变化 0.07。相对于这些转移：

- 标准证据只在搜索预览中新出现时，S 额外增加 2.33，95% 重采样范围为 1.77 到 2.77；
- 提交此前已经在预览中见过的证据时，S 额外增加 2.11，范围为 1.72 到 2.49；
- 提交此前未匹配到的证据时，S 额外增加 2.18，范围为 1.60 到 2.72。

![不同证据事件引起的 S 变化](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/05-evidence-gain-response.png>)

**图 5｜证据事件与 S 的局部变化。** 点为控制协变量后的平均差，横线为按题目重采样的 95% 范围。

最关键的不是三组精确排序，而是它们的量级相近：**仅仅让标准证据出现在搜索预览中，就能产生与正式提交证据相当的 S 增量。** 这直接解释了 S 为什么会领先 R。

这仍是观察性回归，不能排除某些不可观测的状态差异；但它比只比较整条时间曲线更接近机制，因为比较对象是相邻状态的局部变化，并控制了此前状态。

## 第六轮：搜索预览能否解释 S 的反转

正 S 并不是单调状态。在 985 个“前一状态 S 为正”的转移中，103 次重新变成非正。反转是否发生与当前 context 里是否仍有标准证据预览高度相关：

- R 不完整且当前无标准证据预览：反转率 20.3%；
- R 不完整且当前仍有标准证据预览：反转率 7.4%；
- R 完整且当前无标准证据预览：反转率 12.1%；
- R 完整且当前仍有标准证据预览：反转率 0.6%。

![S 反转与当前搜索预览](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/06-reversal-by-preview.png>)

**图 6｜当前搜索预览与 S 反转。** 无论 R 是否完整，当前仍显示标准证据预览时，S 都更不容易退回非正。

控制 R 是否完整、检索时间、前一状态 S 和实验轮次后，当前存在标准证据预览对应的反转风险仍低 13.7 个百分点，95% 重采样范围为低 20.0 到 8.3 个百分点。

这说明 S 不是只由“历史上累计获得了多少证据”决定。当前工作记忆里什么内容仍然显眼，也会明显改变它。

## 第七轮：时间、已提交证据和可见证据分别解释多少 S

我们用按问题分组的十折交叉验证预测每个状态的连续 S，确保同一道题的三轮轨迹不会同时进入训练集和测试集。模型允许时间和覆盖率产生非线性关系。随后把三组变量在所有可能的加入顺序下带来的预测提升取平均，以减少共线变量的顺序依赖。

只包含实验轮次和标准证据跳数的基础模型，跨题目预测 R² 为 0.021。加入全部变量后，R² 达到 0.498。相对基础模型增加的 0.477 可以分解为：

- 当前预览和累计可见证据贡献 0.248；
- 检索进度贡献 0.174；
- 已提交证据贡献 0.056。

![S 的跨题目预测解释度分解](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/07-predictive-r2-decomposition.png>)

**图 7｜三组信息对 S 跨题目预测能力的平均贡献。** 横线为按题目重采样的 95% 范围。

可见信息组贡献了新增解释度的大约 52%，是已提交证据组的四倍以上。这不是因果归因：时间、预览和 read 本来就共同演化，解释度的分摊取决于所选特征。它能够支持的较弱但重要结论是：**在从未见过的新问题上预测 S 时，搜索预览提供的信息明显不能被 R 或时间替代。**

## 第八轮：R 与 S 在终止状态如何共同对应正确性

终止状态出现一个清楚的门槛关系：

| 已提交证据 | S 状态 | 轨迹数 | 答对数 | 正确率 |
|---|---:|---:|---:|---:|
| R 不完整 | S 非正 | 29 | 1 | 3.4% |
| R 不完整 | S 为正 | 98 | 5 | 5.1% |
| R 完整 | S 非正 | 10 | 3 | 30.0% |
| R 完整 | S 为正 | 163 | 124 | 76.1% |

![终止状态中的 R 与 S 门槛](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/08-terminal-evidence-gate.png>)

**图 8｜R 和 S 对终止答案正确率的共同关系。** R 不完整时，两种 S 状态都几乎无法答对；R 完整后，正 S 才对应明显更高的正确率。

在 R 不完整时，正 S 与非正 S 的正确率只差约 1.9 个百分点，95% 重采样范围跨过 0；在 R 完整时，两者相差约 46.2 个百分点，范围为 18.7 到 76.0。两种 R 条件下的差异再相减，交互差为 44.4 个百分点，范围为 15.9 到 74.2。

这支持“R 是门槛、S 在门槛后提供增量信息”的解释。但 R 完整且 S 非正的终止状态只有 10 个，46.2 个百分点的精确大小仍不稳定；更可靠的是方向和三轮一致性，而不是单个点估计。

## 第九轮：同一道题跨运行比较，排除固定题目难度

R 与正确性的关系可能只是因为容易问题更容易检索，也更容易回答。三轮独立运行让我们能够在同一道题内部比较：选出一轮 R 完整、另一轮 R 不完整的运行对，从而自动控制题目本身不随运行变化的难度。

一共得到 72 个覆盖状态不同的同题运行对：

- 42 对是 R 不完整时答错、R 完整时答对；
- 27 对两边都答错；
- 3 对两边都答对；
- 0 对出现 R 不完整时答对、R 完整时反而答错。

![同题运行对的答案变化](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/09-within-question-pairs.png>)

**图 9｜同一道题在 R 不完整与 R 完整运行中的答案结果。** 右上格的 42 表示补齐证据后由错变对；左下格为 0，表示样本中没有反向变化。

按题目聚类后，R 完整相对 R 不完整对应 58.3 个百分点的同题正确率提升，95% 重采样范围为 43.1 到 72.2 个百分点。这比跨题目的总体相关性更有说服力，因为固定题目难度已经被配对消除。

它仍然不是随机干预：同一次运行中能够完成检索，也可能反映该轮产生了更好的查询、工作记忆或推理状态。因此可以说 R 与结果存在强烈的同题关联，但严格的因果结论仍需主动控制 handoff。

## 第十轮：如果把信号用于选择性作答，应该怎样组合

最后只看 300 个终止状态，模拟一个“按可信程度排序、只保留一部分答案”的使用方式。为避免 J 大量并列为 1 带来的任意排序，并列分数按随机抽取的期望正确率处理。

当只保留排名前 25% 的答案时：

- 只用 J 排序，正确率为 50.3%；
- 只用 S 排序，正确率为 64.0%；
- 先要求 R 完整，再按 S 排序，正确率为 82.7%。

当保留前 50% 时，三者分别为 50.3%、58.7% 和 76.7%。总体不筛选时正确率为 44.3%。

![J、S 与 R 加 S 的选择性正确率](</Users/johnnychiu/Documents/memory harness from the first principle/picorer/experiments/sufficiency-dynamics-20260912/analysis-rs-v3/ten-pass/10-selective-accuracy.png>)

**图 10｜保留比例与正确率。** 红线先执行 R 门槛，再用连续 S 排序；它在大部分保留比例上明显优于单独使用 J 或 S。

这给出一个直接的工程含义：如果要用现有信号控制是否信任答案，最合理的规则不是单独设一个 S 阈值，而是**先检查 evidence handoff 是否完整，再用 S 表示剩余的不确定性。**

这只是终止答案的回顾性选择分析，不能证明在中间状态提前停止也会得到同样正确率。现有数据没有为每个中间状态重新生成答案，因此没有虚构该反事实。

## 十轮结果合在一起说明什么

第一轮排除了一个简单解释：S 的动态不是两个服务之间的随机噪声。第二轮则排除了原始验证方案：J 虽然可复现，却在没有检索的状态上几乎全部判断充分。

第三到第七轮共同确定了 S 的语义。S 大多在标准证据进入搜索预览时转正，通常领先正式 read；只在预览中出现新证据，也会产生与正式提交相当的 S 增量；当预览不再出现时，正 S 更容易反转；在跨问题预测中，可见信息比已提交证据解释更多 S。S 因而更接近“当前 context 看起来是否足够作答”，而不是“下游答案阶段已经拿到什么”。

第八到第十轮确定了 R 和 S 的分工。R 不完整时，正 S 几乎没有答案价值；R 完整时，S 才能进一步区分结果。同一道题的配对分析也显示，证据补齐与由错变对存在强烈关联。最终，R 门槛和 S 排序的组合明显优于任何单一信号。

## 对 Picorer 系统设计的具体诊断

当前系统允许以下链条发生：

1. `search` 预览暴露部分或全部关键证据；
2. agent 的 S 上升并选择结束；
3. 触发 S 的预览没有全部经过 `read`；
4. evidence handoff 只传递已提交证据；
5. 答案模型在比 agent 判断充分时更贫乏的上下文上作答。

因此，值得优先修复的不是 S 的数值标定，而是**让 finish 的依据与 answer 的输入保持一致**。最直接的受控实验应比较：

1. 保持当前 preview-only 流程；
2. finish 前自动 `read` 支持该决定的搜索结果；
3. 直接把触发 finish 的最后预览交给答案阶段；
4. 计算 finish margin 时隐藏未提交的搜索预览。

如果第 2 或第 3 个条件显著修复“R 不完整但 S 为正”的错误，就能把目前的观察性 preview–handoff 解释升级为直接的机制证据。

## 不能越过的数据边界

- 搜索预览覆盖采用严格的标准化文本精确匹配，会漏掉释义和非原句表达，因此“看见过标准证据”的统计是保守下界。
- 累计可见证据表示某条信息此前出现过，不保证模型在后续状态中仍完整记住；第六轮因此另外使用“当前预览”分析反转。
- 三轮都来自同一模型、同一 benchmark 的 100 道题；副本可靠性不能推出跨模型泛化。
- 终止状态的部分子组较小，尤其是 R 完整且 S 非正的 10 条轨迹。
- 除同题配对外，大部分结果仍是观察性关系；配对也只能消除固定题目难度，不能消除运行内推理质量差异。
- 当前没有中间状态的独立答案和 correctness，不能离线证明任何提前停止策略的真实收益。

## 自我审查

- **贡献是否清楚：** 清楚。结果不再只是 R–S 相关性，而是定位到 agent 可见上下文与答案 handoff 不一致。
- **叙述是否连贯：** 十轮按“测量是否可信—S 响应什么—什么决定 correctness—如何组合使用”展开。
- **实验是否足够强：** 已使用负对照、相邻状态变化、按问题分组交叉验证、5,000 次问题级重采样和同题配对；因果环节仍缺主动干预。
- **评价是否完整：** 同时覆盖 S、J、R、预览可见证据、终止正确性和选择性作答；跨模型、跨 benchmark 泛化尚未覆盖。
- **系统解释是否过度：** 报告将预测分解和配对结果明确限定为观察性证据，并把 preview–handoff 的因果主张留给下一步受控实验。
