# Changelog

## 1.0.0 - 2026-09-16

Picorer's first independent public release.

- Deterministic ingest over immutable source memory with SQLite persistence.
- Agent-directed `search` → `read` → `finish` evidence acquisition.
- Lexical, dense, temporal, numeric, coverage, and history retrieval operators.
- Exact evidence handoff with citations, provenance, and bounded working memory.
- Optional Qdrant HNSW retrieval with verified generations and SQLite fallback.
- Reproducible MemoryAgentBench, MemoryArena, LongMemEval, AMA-Bench, and
  τ-Knowledge integrations.
- Released evidence--sufficiency experiment data, analyses, reports, and
  publication figures.
