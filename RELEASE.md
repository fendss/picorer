# Picorer v1.0.0

Picorer v1.0.0 is the first independent public release of Picorer.

The public repository uses a clean Git history and the canonical `Picorer`,
`picorer`, and `PICORER_*` namespaces throughout code, configuration, runtime
identities, documentation, and released experiment artifacts. Only the
canonical Picorer namespace is part of the public interface.

The release contains:

- the TypeScript runtime, CLI, HTTP services, and benchmark integrations;
- complete system, implementation, evaluation, deployment, and operations
  documentation under `docs/picorer-v1.0.0/`;
- structured experiment data, analysis code, tables, reports, and figures under
  `experiments/`;
- an artifact manifest and numerical integrity validation for released data.

Machine-local environments, caches, generated build output, redundant QA
bundles, credentials, and the unreleased raw terminal-request archive are not
part of the repository.
